## 11. Plataforma: con archivos y git

Úsalo en Claude Code, Hermes, Codex o cualquier agente que pueda leer el repo y hacer commit.

- Lees los archivos directamente del repo (§2). Antes de editar, trae lo último (`git pull`).
- Guardas como dice §7 *Con herramientas de archivos* y §8 *Guardar en el repo*: commit y push a `main` solo después de un `ok`.
- Si el push falla, dilo y entrega el parche de §7.
