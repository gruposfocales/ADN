#   gf-inicio: repos.py (pulso, menú, informe, git_pr, validar, nuevo proyecto)
# Columnas (separadas por espacios):
#   repo    nombre del repo en github.com/gruposfocales
#   clase   proyecto = lleva ficha index.md y sale en el menú (1A, 1B… en este orden)
#           sistema  = agente de apoyo (inicio = el orquestador, diseñador)
#           datos    = no es agente: solo datos (gf-bibliotecario: catálogo, log, plantillas). Se trae, sin perfil
#           nucleo   = no es agente (ADN): no va al catálogo (datos tampoco)
#   perfil  perfil y atajo de Hermes ("default" = el atajo inicio; "-" = sin perfil)
